# Reference App Feature Adoption

## Adopt

- Clip context toolbar, fast split, deletion before or after playhead, and selected-range retention.
- Direct timeline manipulation, multitrack editing, mask and background controls, and keyframe controls.

## Exclude

- Reference app visual styling, subscription mechanics, advertising, sales prompts, and any design that changes the approved MINDLE UI SSOT.

## Acceptance

Each adopted workflow must be available through the approved layout and have a state or integration test before it is marked available.
