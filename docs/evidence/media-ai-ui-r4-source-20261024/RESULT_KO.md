# MINDLE MEDIA AI R4 UI 소스 보강 결과

기준일: 2026-10-24 KST

## 판정

**SOURCE PASS / WINDOWS CANDIDATE NOT INCLUDED**

실제 Windows R3 화면 `CHROME_REOPEN_EXPORT.png`와 현재 Owner 기준인 `VIDEO 좌측 / PHOTO 우측` 승인 참고본을 1536×1024에서 대조했다. 과거 상하 배치 F27E 이미지는 현재 배치 권한으로 사용하지 않았다.

## R3에서 확인한 차이

- 상단 제목과 VIDEO/PHOTO 좌우 구조, 색상 계열, PHOTO 가로 Preview, 세로 Auto Fit, 7개 보정, 자연어 입력은 보존됐다.
- 실제 입력 영상의 미디어 목록이 파일명 중심 타일로 표시돼 승인 참고본보다 AI 제작 작업 공간의 시각적 정보가 약했다.
- VIDEO/PHOTO 배너에 승인 참고본의 영상·사진 제작 문맥이 충분히 드러나지 않았다.
- 실제 디코딩 프레임과 오디오 파형은 생성됐지만 Timeline의 시각적 구분과 깊이가 승인 참고본보다 약했다.
- R3 화면은 실제 엔진 결과 화면이며, 이번 소스 보강 이전 후보다.

## 적용한 최소 보강

- 기존 VIDEO 좌측 / PHOTO 우측 DOM과 모든 `data-*` 실행 연결을 보존했다.
- 저장소에 이미 포함된 demo 자산만 사용해 VIDEO/PHOTO 헤더 배너의 제작 문맥을 복원했다.
- `/api/assets`의 실제 사진은 이미지 썸네일로, 실제 영상은 로컬 영상 첫 프레임 타일로 표시하도록 연결했다.
- 파일명은 썸네일 위 가독성 레이어로 유지했다.
- 실제 디코딩 Timeline의 프레임·파형·자막·효과 구조는 그대로 두고 시각적 구분만 강화했다.
- 제목, 색상, PHOTO 7보정, 광고 숏폼, 저장, 내보내기, 자연어 입력의 실행 연결은 변경하지 않았다.

## 검증

- UI Node: 27 PASS
- 관련 Python: 22 PASS / 1 SKIP
- 승인 구조 계약 테스트에 배너와 실제 미디어 썸네일 요구를 추가했다.
- 현재 실행 환경에는 Playwright 브라우저 바이너리가 없어 수정 후 새 Chrome 픽셀 캡처는 생성하지 않았다. R3 이전 실제 화면과 소스 계약 검증을 구분한다.

## 후보 경계

검증된 `MINDLE_MEDIA_AI_PC_TEST_20261024_R3`는 Windows 엔진·재시작·Export·독립 readback PASS 후보다. 이번 UI 보강 소스는 R3 ZIP에 포함되지 않는다. Build Gate는 false로 유지하며, 사무실 PC 인수용 새 후보가 필요하다고 자동 확대하지 않는다. 다음 후보가 별도로 승인될 경우 이 UI 소스 포함 여부와 실제 1536×1024 Chrome 화면을 다시 검증해야 한다.
