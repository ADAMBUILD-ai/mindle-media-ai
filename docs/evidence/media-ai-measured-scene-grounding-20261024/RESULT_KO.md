## 이번에 강화한 부족점

직전 건축 영상 에이전트는 Qwen이 서버가 제공한 영상 목록의 순서와 길이를 계획하고 FFmpeg가 조립하는 데까지 연결됐다. 그러나 계획 입력에는 파일 이름·해상도·전체 길이만 있었으며 실제 영상 픽셀의 상태와 사용할 시작 구간은 반영되지 않았다.

이번 변경은 기존 계획기·큐·조립기를 다시 만들지 않고 다음 측정 단계를 기존 경로에 추가했다.

1. OpenCV가 실제 원본 프레임을 디코딩한다.
2. 노출, 움직임, 선명도, 사용 가능한 프레임 비율, 화면 방향을 측정한다.
3. Qwen에는 파일 경로 대신 기존 별칭과 제한된 측정 요약만 제공한다.
4. Qwen이 순서와 장면 길이를 정하면 측정 엔진이 해당 길이에서 점수가 가장 높은 시작 구간을 다시 계산한다.
5. FFmpeg는 `start_seconds + duration_seconds` 구간만 잘라 H.264/yuv420p/AAC/faststart MP4로 조립한다.
6. 시작점과 길이가 실제 원본 범위를 벗어나면 게시 전에 차단한다.

측정 결과는 생성형 시각 이해가 아니다. Evidence에는 `model_inference=false`, `semantic_understanding=false`를 고정해 일반 영상 분석과 생성형 Qwen 계획을 구분했다.
