# MINDLE MEDIA AI 사용 설명서 v1.0

Date: 2026-10-03

## 1. 실행

권장 실행 방법:
Windows 바탕화면의 "MINDLE MEDIA AI - 최종 UI" 아이콘을 더블클릭한다.

정상 실행 시:
- 로컬 MEDIA AI 서버가 자동 확인/실행된다.
- 브라우저가 열린다.
- MINDLE MEDIA AI 화면이 표시된다.

아이콘을 눌러도 열리지 않으면:
- 반복 클릭하지 말고 PC Work 검수 대상으로 기록한다.
- UI 파일을 직접 수정하지 않는다.

## 2. 화면 구성

MEDIA AI는 크게 두 영역이다.

상단:
VIDEO 영상 편집

하단:
PHOTO 사진 편집

각 영역은 기본적으로:
좌측 = 파일 / 자연어 작업 지시
중앙 = Preview / 작업 결과
우측 = 세부 편집 도구

## 3. VIDEO 사용법

### 영상 불러오기
"영상 불러오기"를 누르고 원본 영상을 선택한다.

### AI 자동 편집
"AI 자동 편집"을 누르면 AI 편집 흐름을 실행한다.

### 광고 숏폼
"광고 숏폼"을 누르면 Marketing AI 연계 숏폼 모드로 들어간다.

현재 최종 버튼 순서:
영상 불러오기
→ AI 자동 편집
→ 광고 숏폼
→ 프로젝트 저장
→ 내보내기

### 자연어 지시
좌측 입력창에 원하는 편집 내용을 입력한다.

예:
- "15초 광고 영상으로 만들어줘"
- "도입부를 빠르게 하고 마지막에 브랜드 화면을 넣어줘"
- "밝고 선명한 느낌으로 편집해줘"

### 참고 이미지
"참고 이미지 추가"를 눌러 스타일이나 디자인 참고 이미지를 넣는다.

참고 이미지는 원본 영상을 대체하지 않는다.

### 중앙 Preview
편집 결과를 확인한다.

### Timeline
영상 길이, 장면, 자막, 오디오 등의 배치를 확인한다.

### 우측 편집
자르기 / 분할 / 회전 / 속도
밝기 / 대비 / 채도
흔들림 보정 / 노이즈 제거 등을 조정한다.

## 4. PHOTO 사용법

### 사진 불러오기
"사진 불러오기"를 눌러 사진을 선택한다.

### 자연어 지시
왼쪽 입력창에 원하는 사진 편집 내용을 입력한다.

예:
- "노을 분위기로 바꿔줘"
- "건물은 그대로 두고 하늘만 더 맑게 해줘"
- "배경을 정리하고 선명도를 높여줘"

### 참고 이미지
원하는 분위기나 재료 느낌의 참고 이미지를 추가한다.

### 중앙 Preview
사진 결과를 크게 확인한다.

### AI 보정
AI 기반 보정 기능을 실행한다.

### 세부 편집
우측에서:
- 자르기
- 크기 조절
- 회전
- 좌우/상하 반전
- 밝기
- 대비
- 채도
- 선명도
를 조정한다.

## 5. 프로젝트 저장

작업 중 "프로젝트 저장"을 사용한다.

중요:
저장 후 프로그램을 다시 열었을 때 기존 작업을 다시 불러올 수 있는지 확인해야 한다.

## 6. 내보내기

VIDEO:
최종 영상 파일을 내보낸다.

PHOTO:
최종 이미지 파일을 내보낸다.

광고 숏폼:
최종 MP4가 생성된 경우 Preview와 Export에서 확인한다.

## 7. 광고 숏폼 사용

광고 숏폼은 별도 프로그램이 아니다.
MEDIA AI 안에서 실행된다.

기본 흐름:
Marketing AI 기획
→ Shortform Bridge
→ MEDIA AI
→ Preview
→ Timeline
→ MP4 Export

현재 확인된 기본 출력 기준:
- 세로 9:16
- 15초
- H.264 영상
- AAC 오디오
- BGM
- 자막
- 장면 전환
- 브랜드 아웃트로

음성 나레이션은 승인된 TTS 모델이 확보되기 전까지 별도 검증 항목이다.

## 8. 문제가 생겼을 때

### 바탕화면 아이콘이 안 열림
UI를 수정하지 말고:
- 바로가기
- 런처
- 서버
- 포트 8768
를 확인한다.

### 작업 폴더 화면과 바탕화면 화면이 다름
두 UI를 따로 수정하지 않는다.

확인 순서:
1. 같은 저장소인가
2. 같은 Branch인가
3. 같은 HEAD인가
4. 같은 서버인가
5. 같은 UI 파일 Hash인가
6. 오래된 서버/브라우저 캐시가 남아 있는가

### 화면이 잘림
먼저 실제 실행본이 같은지 확인한다.
다른 실행본 문제를 UI 크기 수정으로 해결하지 않는다.

## 9. 사용 원칙

- 작업 폴더가 제품 원본이다.
- 바탕화면 아이콘은 그 제품을 실행하는 수단이다.
- VIDEO와 PHOTO는 서로 독립된 편집 영역이다.
- 참고 이미지는 원본을 대체하지 않는다.
- 요청하지 않은 영역까지 함께 변경되면 결함으로 본다.
- 저장/내보내기는 실제 파일 생성까지 확인한다.

## 10. 권장 작업 순서

실행
→ 원본 불러오기
→ 자연어 지시 또는 AI 기능
→ Preview 확인
→ 필요한 세부 수정
→ 프로젝트 저장
→ 최종 확인
→ 내보내기

광고 숏폼은:
실행
→ 영상 불러오기
→ 광고 숏폼
→ 기획/장면 확인
→ Preview
→ Timeline
→ Export
